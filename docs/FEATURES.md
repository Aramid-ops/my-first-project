## 1. Խանութ / սրճարան / ռեստորան
1. ✅ Գլխավոր էջ. առաջարկվող մատակարարներ (քառակուսիներով), «Իմ մատակարարները», ուղարկված հայտեր
2. ✅ **«Բոլոր մատակարարները»** — քառակուսիներով, ըստ ոլորտի → ֆիրմայի էջ (մեր մասին, ՀՎՀՀ, հասցե, հեռախոս, նվազագույն պատվեր, տեսականի՝ առանց գների) → «Միանալ որպես հաճախորդ»
2a. ✅ **Որոնում բոլոր մատակարարների մոտ** — դասավորել՝ համապատասխան / էժանից / թանկից / 📍 մոտիկից / 🔥 շատ վաճառվող; երևում է գինը, մատակարարը, թաղամասի մենեջերը, հեռավորությունը, 📞 զանգ
2a1. ✅ Որոնման մեջ՝ **շուկայի գինը** (ամենաէժան – ամենաթանկ, միջին), «Միջինից X% էժան», և ամեն չմիացած մատակարարի մոտ՝ «Ուղարկեք հայտ. գուցե ձեզ համար գինը ավելի մատչելի լինի» [Ուղարկել հայտ]
2b0. ✅ **🔴 Live շուկա** — երկու ակնթարթային պատուհան. «🛒 Խանութները ուզում են» և «💼 Մատակարարները առաջարկում են» → «🙋 Հետաքրքրված եմ»; գլխավոր էջում՝ «📣 Ի՞նչ է ձեզ պետք» դաշտ (գրել → Enter)
2b. ✅ **📣 Փնտրում եմ մատակարար** — գրում է ինչ է պետք (գինը՝ ըստ ցանկության) → մատակարարները ուղարկում են առաջարկ (տեքստ + գին) → «Դիտել և միանալ»; ծանուցում
2c. ✅ «Երևալ մատակարարներին» անջատիչ («Իմ տվյալները»)
3. ✅ Մատակարարի կատալոգ՝ նկարներով, միավորներով, իր անհատական գներով
4. ✅ **Մեկ զամբյուղ բոլոր մատակարարների համար** → ինքը բաժանվում է ըստ ֆիրմայի
5. ✅ Առաքման օրը և պատվերի վերջնաժամը ամեն մատակարարի համար
6. ✅ Նվազագույն պատվերի և պարտքի սահմանաչափի ստուգում
7. ✅ Պատվերներ՝ ըստ օրերի (Այսօր / Երեկ / ամսաթիվ) և կարգավիճակ (Նոր → Ընդունված → Ճանապարհին → Առաքված), պատմությունը

11. ✅ Մատակարարներ, որոնք հավելվածում չեն → պատվեր WhatsApp / Viber / SMS-ով; համարի ստուգում (+374 ինքնաբերաբար), ✏️ փոխել / 🗑 ջնջել; «Ինչ է մատակարարում» (օր.՝ ածուխ); միշտ երևում են «Իմ մատակարարները»-ում; ուղարկված պատվերը մնում է «Պատվերներ»-ում (ըստ օրերի)

10b. ✅ **«🏪 Բոլոր խանութները»** — որոնում, թաղամաս, 📍 մոտիկից, 📞 զանգ, «Ձեր հաճախորդն է»
