# Մատակարար · հավելված (Expo)

Մեկ կոդ → Android, iPhone, վեբ։ Նկարագրությունը՝ [../docs/SPEC.md](../docs/SPEC.md)։

## Ինչ կա հիմա (փորձնական տարբերակ)
- Մուտք՝ ընտրությամբ (խանութ / մենեջեր Կարեն)
- **Խանութ.** իմ մատակարարները (մենեջեր, առաքման օր) → ապրանքներ (նվազագույն քանակ, քայլ, «Չկա») → ընդհանուր զամբյուղ → ուղարկել (բաժանվում է ըստ մատակարարի) → պատվերների կարգավիճակ
- **Մենեջեր.** նոր պատվերներ → Ընդունել → Փոխանցել (լռելյայն հասցեատիրոջը)
- Տվյալները առայժմ հիշողության մեջ են (`src/lib/demo-data.ts`, `src/lib/store.tsx`)

## Գործարկել
```bash
npm install
npx expo start        # հեռախոսում՝ Expo Go հավելվածով սկանավորիր QR կոդը
npx expo start --web  # բրաուզերում
```

## Ստուգումներ
```bash
npx tsc --noEmit
```
